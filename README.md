🩺 Diabetes Prediction Model using Deep Learning
This project provides a deep learning-based solution for predicting the likelihood of diabetes in patients using key health indicators. The model is built using TensorFlow and Keras, and it leverages important clinical data such as age, BMI, glucose levels, hypertension status, and more to make accurate predictions.

🔍 Features
📊 Predicts diabetes based on patient input data

🤖 Trained deep learning model using TensorFlow/Keras

🔄 Scales input data using pre-fitted StandardScaler (scaler.pkl)

✅ Simple and user-friendly prediction interface (CLI-based)

💾 Model and scaler included for local predictions

🧠 Input Features
gender (0 = Female, 1 = Male)

age (in years)

hypertension (0 = No, 1 = Yes)

heart_disease (0 = No, 1 = Yes)

smoking_history (0 = No info, 1 = Current, 2 = Ever, 3 = Former, 4 = Never, 5 = Not current)

bmi (Body Mass Index)

HbA1c_level (Glycated Hemoglobin)

blood_glucose_level (Fasting blood sugar level)
